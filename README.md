## setchy.io — Adam Setch

Adam Setch's personal site: [setchy.io][setchyio]. Built with [Astro][astro]
(static output), deployed to [Netlify][netlify-deploys].

## Tech stack

- **Astro 7** — static output, `src/pages/*.astro` routes + `src/content/sections/`
  content collections (blogs, radars) rendered through `[...slug].astro`
- **pnpm** — package manager (Node 24, pinned in `.nvmrc` / `packageManager`)
- **Design tokens** — CSS custom properties in `src/styles/global.css`
  (light + dark themes, indigo accent)
- **Self-hosted fonts** — Inter / JetBrains Mono via
  `@fontsource` (latin subsets only)
- **Icons** — Font Awesome SVG paths rendered as CSS masks
  (`src/styles/icons.css`, generated — no icon fonts)

## Local development

```
pnpm install
pnpm run dev        # http://localhost:4321
```

## Build & check

```
pnpm run build      # static output to dist/
pnpm astro check    # type-check templates + data
```

## Scripts

| Script | Purpose |
|---|---|
| `pnpm run fetch:github` | Refresh GitHub repo/org stats → `src/data/github-cache.json`, `stats.json` (also runs weekly in CI via the "Refresh site stats" workflow) |
| `pnpm run fetch:travel` | Refresh Skratch travel stats → `src/data/travel.json` |
| `pnpm run generate:icons` | Rebuild `src/styles/icons.css` from Font Awesome SVG paths (rerun when adding icons) |
| `pnpm run generate:skills-badge` | Refresh the skills badge |

## Content

- **Permanent pages** — `src/pages/*.astro` (About, Open Source, Industry,
  Library, Travel)
- **Content sections** — `src/content/sections/*.md` with frontmatter
  (`title`, `date`, `tags`, `permalink`, `cover`); rendered by
  `src/pages/[...slug].astro`
- **Data** — typed data modules in `src/data/` (`projects`, `industry`,
  `library`, `skills`, travel/github caches), consumed from typed `*.json`
  files regenerated by the fetch scripts

## Notes

- Open Graph images are generated automatically at build time via
  `astro-og-canvas` (CanvasKit-rendered PNGs at `/open-graph/<page>.png`,
  tinted with the site palette and bundled Inter fonts); `og:image`
  is derived from the page path.
- The site is deployed from `main`; build command `pnpm run build`, publish
  directory `dist` (see `netlify.toml`).
